# 暖暖衣柜

奇迹暖暖衣柜管理与关卡搭配工具。入口为 `index.html`，可发布到提供 HTTPS 的静态网站托管服务。

## 使用与备份

电脑或手机通过网站链接访问。衣柜、关卡进度和个人记录保存在当前浏览器。换设备时，在原设备的“数据与更新”中下载完整备份，再在新设备读取备份并确认合并。

## 发布到 GitHub Pages

1. 在自己的 GitHub 账号下创建公开仓库。
2. 将本目录的 `index.html`、`.nojekyll` 和本说明上传到仓库根目录。
3. 在仓库的 Settings → Pages 中选择 Deploy from a branch，分支选 main，目录选 /(root)，保存。
4. 等待发布完成，通过 Pages 页面提供的 Visit site 链接访问。

发布端需要登录 GitHub；访客直接打开发布后的网站链接即可。实际手机访问仍需在发布后验证。

官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
